# IPNumber Application

This application provides a simple JavaScript function to fetch and display the user's IP address. It uses the `https://ipinfo.io/ip` API to retrieve the IP address and displays it dynamically on a webpage.

## Features
- Fetches the user's IP address.
- Displays the IP address in a user-friendly format.
- Includes error handling for failed API requests.

## How to Use
1. Open the `index.html` file in any modern web browser.
2. The application will automatically fetch and display your IP address.

## Requirements
- A modern web browser with JavaScript enabled.
- Internet connection to access the `https://ipinfo.io/ip` API.
